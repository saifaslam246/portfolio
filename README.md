# Saif Rehman - Portfolio Website

A stunning, modern portfolio website built with React, Tailwind CSS, and Framer Motion. This portfolio showcases professional skills, projects, and provides a beautiful way to connect with potential clients and employers.

## ✨ Features

- **Modern Design**: Clean, professional design with gradient effects and glass morphism
- **Responsive**: Fully responsive design that works on all devices
- **Smooth Animations**: Beautiful animations powered by Framer Motion
- **Interactive Navigation**: Smooth scrolling navigation with active section highlighting
- **Contact Form**: Integrated contact form for easy communication
- **Social Links**: Direct links to LinkedIn, GitHub, and other social profiles
- **Performance Optimized**: Fast loading with Vite build tool

## 🚀 Technologies Used

- **React 18** - Modern React with hooks and functional components
- **Vite** - Fast build tool and development server
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library for React
- **React Icons** - Beautiful icon library
- **PostCSS** - CSS processing

## 📦 Installation

1. Clone the repository:
```bash
git clone <your-repo-url>
cd saif-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`

## 🛠️ Build for Production

To create a production build:

```bash
npm run build
```

The built files will be in the `dist` directory.

## 🎨 Customization

### Colors
The color scheme can be customized in `tailwind.config.js`. The primary colors are defined in the `colors.primary` object.

### Content
Update the content in `src/App.jsx` to match your personal information:
- Personal details and bio
- Skills and technologies
- Project information
- Contact details

### Styling
Custom styles can be added in `src/index.css` using Tailwind's `@layer` directive.
